# macbeth76.github.io

Personal portfolio and blog website hosted on GitHub Pages.

## Overview

Static website showcasing professional experience, projects, blog posts, books, and podcasts.

## Content

- **Portfolio:** Professional experience and achievements
- **Blog:** Technical articles and insights
- **Books:** Reading list and recommendations
- **Podcasts:** Podcast appearances and recommendations
- **Profile:** Professional bio and contact information

## Technology

- Static HTML/CSS/JavaScript
- GitHub Pages hosting
- Responsive design
- SEO optimized with Open Graph and Twitter Card metadata

## Files

- `index.html` - Main portfolio page
- `style.css` - Styling
- `books.json` - Book data
- `podcasts.json` - Podcast data
- `blog/` - Blog posts in Markdown
- `profile.jpg` - Profile image
- `banner.jpg` - Banner image

## Deployment

Automatically deployed via GitHub Pages from the main branch.

**Live Site:** https://macbeth76.github.io/

## Local Development

Simply open `index.html` in a browser or use a local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

- Open Graph metadata for social sharing
- Twitter Card support
- LinkedIn optimization
